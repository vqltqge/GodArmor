# God Armour

This plugin adds a set of overpowered armour to the game. Each piece gives you different potion effects, and wearing the entire set will give you a dash ability. Here is what each piece gives you:

## Helmet

* Hero of the Village X

## Chestplate

* Strength II

## Leggings

* Speed II

## Boots

* Dolphin's Grace
* Water Breathing

## Full Set

Wearing the full set will let you dash in the direction you are looking.

## Commands

### `/dash`

When wearing the full set, use the command `/dash` to dash forward. There is a 5 second cooldown.

### `/godarmor`

Opens a GUI that lets you obtain the armour pieces by clicking on them.
